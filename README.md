Проект по веб-разработке, вариант глоссария на биологическую тематику, с возможностью закрепления материала в формате теста. 
Основные функции:
Просмотр терминов.
Добавление новых терминов через форму (требует модерации).
Настройка количества вопросов для каждого теста.
Случайная выборка терминов с вариантами ответов.
Автоматическая проверка правильности ответов.
Анализ ошибок по тематикам.
Ранжирование проблемных тем.
Отображение общего количества пройденных тестов.
